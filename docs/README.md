# Docs

## Plans are history, not instructions

`plans/` and `superpowers/plans/` hold dated design and implementation plans.
They record what was intended at the time they were written. They are not kept
current.

Several of them target the Python broker (`deepline_gtm_agent/`,
`managed_agent/`, `server.py`) and its Railway and Azure deployment paths. That
code is deleted. Those plans cannot be executed as written and are kept only for
the reasoning they capture.

For how the system works now, read the root [README.md](../README.md) and
[SETUP.md](../SETUP.md).
